## Delivered behavior

`/interview` is a usable English preparation path for master's students targeting
bank derivatives roles. Six original cases have six different conceptual transfer
tasks: call/put, dividend carry, signed hedges, gamma/vega shocks, time/rates and a
final quote-and-risk memo. Public task DTOs omit solutions. Numerical answers and
a written method precede computed feedback; explicit reference reveal and retries
cannot become new independent passes. Written reasoning uses a recorded
self-review rubric, not a fabricated expert or AI grade.

The first case runs anonymously with a visibly unsaved result. A signed free
learner can use the full pilot and save original attempts, feedback, self-review,
current task and a private report. A fresh browser restores the saved correction
phase and responses; an explicit retry keeps prior answers and history. Context
links load the real calculator with the same ticket. Account ownership,
idempotency, concurrent submission, invalid inputs, exposure and numerical
tolerances are covered by actual HTTP handler tests and independent math oracles.

The admin dashboard includes operator-only participation, activation, transfer
and distinct-day return aggregates. These use actual events, omit personal data
and explicitly distinguish local test activity from customers or willingness to
pay. Reported foreground time excludes hidden/idle tabs and is capped by server
elapsed time; it is not verified attendance.
